=====================================
模块概述
=====================================
操作日志模块是一个完整的系统操作审计解决方案，用于记录系统中所有用户的操作行为，
包括登录、登出、增删改查等操作。该模块提供了完整的日志记录、查询、统计和管理功能。

=====================================
核心功能特性
=====================================

✅ 自动日志记录
   - 支持自动记录所有API操作
   - 中间件自动捕获请求和响应信息
   - 异步记录，不阻塞主流程

✅ 多种操作类型支持
   - CREATE: 创建操作
   - UPDATE: 更新操作
   - DELETE: 删除操作
   - QUERY: 查询操作
   - LOGIN: 登录操作
   - LOGOUT: 登出操作
   - ERROR: 错误操作

✅ 详细记录信息
   - 用户身份信息
   - 请求参数和响应数据
   - IP地址和用户代理
   - 执行时间和状态码
   - 操作描述和模块信息

=====================================
使用方法
=====================================

1. 自动记录日志（推荐）:
   ```typescript
   import { autoOperationLogMiddleware } from './middleware/operationLog'
   app.use(autoOperationLogMiddleware())
   ```

2. 手动记录日志:
   ```typescript
   import { recordCreateLog } from './util/operationLogUtil'
   await recordCreateLog(userId, userName, 'user', '创建新用户', userData)
   ```
